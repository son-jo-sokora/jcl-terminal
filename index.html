JCL 練習端末

ISPF で JCL を書き、SUB で投入すると JES2 のメッセージが返ってきます。ジョブの出力は SDSF で確認できます。

はじめの3ステップ

  1. 左は HELLO メンバーの編集画面です。Command ===> に SUB と入力して Enter。
  2. IKJ56250I と $HASP165 が表示されたら Enter で戻ります。
  3. コマンド行に =SD → ST。ジョブの左に ? で出力一覧、S で中身を表示します。

キー操作

Enterコマンド実行（編集エリアでは改行） Ctrl+Enter編集エリアからでもコマンド実行 F3戻る（編集中は保存して戻る）。Esc でも可 F7 / F8上下スクロール。PgUp PgDn でも可 =2編集、=3.4 データセット一覧、=SD SDSF

  • GDGDEFIDCAMS で GDG ベースを定義（最初に1回）

  • JES2CTL/*PRIORITY /*JOBPARM /*ROUTE /*MESSAGE

  • DDPARMSLIKE / VOL / RETPD / DDNAME / PATH（S213 も発生）

その他の機能

GDGIDCAMS の DEFINE GENERATIONDATAGROUP / DELETE ... GDG FORCE / LISTCAT。DSN=名前(+1) で新しい世代、(0) (-1) で既存の世代、名前だけなら全世代を新しい順に連結します。相対番号はジョブの中で固定されます JES2 文/*JOBPARM（SYSAFF・LINES・COPIES など）、/*PRIORITY、/*ROUTE PRINT、/*MESSAGE、/*NOTIFY、/*XEQ。不正な指定は無視され、JESMSGLG に $HASP119 が出ます。SYSAFF がほかのシステムだと、ジョブは入力キューで待ち続けます OUTPUT 文CLASS・DEST・COPIES・DEFAULT=YES・JESDS。DD 側は OUTPUT=*.名前 と SYSOUT=(,) で参照します DDVOL=SER / VOL=REF（ボリューム違いは S213-04）、LIKE / REFDD / DCB=参照、DDNAME=、RETPD / EXPDT（期限前の削除は不可、IDCAMS は PURGE で可）、PATH 一式（=3.17 でファイル一覧）、OUTLIM（超過で S722）、COPIES、DEST、HOLD、SPIN、FREE JOB / EXECJOBRC、RESTART、JOB の COND、TYPRUN=HOLD / JCLHOLD / SCAN / COPY、REGION（不足すると S80A。JOB 側が優先）、JOBLIB / STEPLIB、IF の ABENDCC、EXPORT、SCHEDULE HOLDUNTL システム記号&SYSUID &SYSNAME &SYSCLONE &LYYMMDD &LHHMMSS &LYR4 など 編集小文字を含むメンバーは CAPS OFF で開きます。CAPS ON / CAPS OFF で切り替えられます

プロシージャと INCLUDE

JCLLIB ORDER= で指定したライブラリを順に探し、見つからなければ SYS1.PROCLIB を探します。USER01.PROCLIB には COPY と DELDS のプロシージャと、INCLUDE グループ STDPRT が入っています。=3.4 の一覧で E を付けると編集でき、コマンド行に SYS1 と入力すると SYS1.PROCLIB を表示します。

記号EXEC の値 → PROC 文の既定値 → SET の値の順に優先されます。DD * に SYMBOLS=JCLONLY を付けるとデータ中の記号も置き換えます EXECPARM.GEN= のように手順ステップ名を付けるとそのステップだけに、付けなければ COND などは全ステップに適用されます。PARM は最初のステップに適用されます DD//GEN.SYSUT1 DD ... で上書きし、該当がなければ追加します。ステップ名のない DD は最後のステップに付きます。DSN= のように値を空にすると、その指定を取り消せます JESJCL展開後の JCL を表示します。XX はカタログ式、++ はインストリーム、X/ +/ は上書きされた行です

構文チェック

編集画面で JCK と入力すると、投入せずに JCL をチェックします。問題のある行を一覧で表示し、エディタの行番号が ==ERR>（エラー）や ==WRN>（警告）に変わります。RESET で印を消せます。

JOB 文に TYPRUN=SCAN を付けて SUB すると、実行せずに JES2 の変換チェックだけを行います。

エラーは発生するタイミングで3段階に分かれます。

変換時綴り・書式の誤り。ジョブは実行されず JCL ERROR。結果は JESYSMSG の STMT NO. MESSAGE に出ます。例: 未定義の命令・キーワード、括弧やアポストロフィの不一致、継続行の誤り、名前やデータセット名の長さ・文字、DISP・SPACE・DCB・COND・CLASS などの値、同時に指定できないキーワードの組み合わせ、重複したキーワード、使われない SET シンボル（警告） 割り当て時実行直前のエラー。存在しないデータセット（IEF212I）、データセットの重複（IGD17101I）、誤った UNIT（IEF210I）。JCL ERROR になります 実行時プログラム実行中のエラー。存在しないプログラム（S806）、BLKSIZE が LRECL の倍数でない（S013-20）、DCB の不一致（IEB311I）、DFSORT や IDCAMS の制御文の誤り

対応範囲

プログラム: IEFBR14、IEBGENER、SORT（ICEMAN）、IDCAMS（LISTCAT・DELETE・PRINT・REPRO）。それ以外の PGM は S806 で ABEND します。

JCL: JOB / EXEC / DD / SET / IF・ELSE・ENDIF / PROC・PEND / JCLLIB / INCLUDE、COND、DISP、DD *、DUMMY、SYSOUT、&SYSUID などのシンボル、後方参照（DSN=*.STEP.DD）。

実機ではなく、ブラウザ上で動くシミュレーションです。メッセージは実際の z/OS を参考にした近似で、番号や文面が実機と異なるものがあります。JCK で始まるメッセージはこの端末独自のヒントです。作ったデータセットとジョブはこのブラウザにだけ保存されます。
