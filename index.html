JCL 練習端末

ISPF で JCL を書き、SUB で投入すると JES2 のメッセージが返ってきます。ジョブの出力は SDSF で確認できます。

はじめの3ステップ

  1. 左は HELLO メンバーの編集画面です。Command ===> に SUB と入力して Enter。
  2. IKJ56250I と $HASP165 が表示されたら Enter で戻ります。
  3. コマンド行に =SD → ST。ジョブの左に ? で出力一覧、S で中身を表示します。

キー操作

SDSF からコマンドを投入する

SDSF の画面で、コマンド行に / に続けて MVS や JES2 のコマンドを入力します。応答はコマンド行の下に重ねて表示され、すべて ULOG に残ります。LOG でシステムログ（ジョブの開始・終了も含む）を表示します。

/D T日付と時刻（IEE136I） /D A,L実行中の作業（IEE114I） /D IPLINFOIPL の情報（IEE254I） /D U,DASD,ONLINEDASD ボリューム（IEE457I） /$DJ'名前'ジョブの状態（$HASP890）。/$DJ1234 のように番号でも可 /$HJ /$AJジョブを保留／解放（実行前のジョブ） /$CJ /$PJジョブを取り消し／出力ごと削除（$HASP250） /$DI /$DSPLイニシエーター／スプールの使用率 /D R,L応答待ちのメッセージ（WTOR）の一覧（IEE112I） /R nn,YES番号 nn の問い合わせに応答（IEE600I）。番号違いは IEE704I /C ジョブ名実行中のジョブを取り消し（IEE301I、ジョブは S222）

知らないコマンドには、MVS は IEE305I、JES2 は $HASP003 を返します。ST 画面の行コマンド H でもジョブを保留できます。

データセットとメンバーを作る

=3.2 で Data Set Utility を開き、Data Set Name に名前を入れて Option に A。Allocate New Data Set 画面で属性を決めて Enter すると作成されます。Directory blocks を 1 以上にすると PDS（メンバーを持てるライブラリー）、0 だと順次データセットです。

名前を ' で囲まないと、先頭に TSO プレフィックス USER01. が付きます（NEW.DATA → USER01.NEW.DATA）。Option R で名前変更、D で削除、空欄で情報表示。

メンバーは、=3.4 の一覧で PDS の左に E を付けてメンバー一覧を開き、コマンド行に S 新しい名前 と入力します。何も書かずに F3 で戻ると、メンバーは作られません。

エディタの行コマンド

行番号（000100 など）の上に文字を上書きして Enter を押します。残った数字は無視されます。

I下に空行を挿入（I5 で5行）。入力して Enter を押すと、次の空行が自動で開きます D行を削除（D3 で3行、DD〜DD で範囲） R行を複製（RR〜RR で範囲） C Mコピー／移動。行き先の行に A（後ろ）か B（前）。範囲は CC／MM

主コマンド: F 文字列 [ALL]、C 旧 新 [ALL]、L 行番号、TOP、BOT、RESET。空のメンバーは '''''' の入力行が並んだ状態で開きます。先頭に行を足すときは ****** の上に I。

連携モード：オペレーターコンソールとつなぐ

MVS コンソール シミュレータを別のタブで連携モードにして開くと、この端末はシステム SYSA の TSO 利用者 USER01 になります。SUB したジョブは、シミュレータの JES2 が実行のタイミングを決めます（$S 前やイニシエーター休止中は待つ、データセットを使用中なら IEF099I で待つ、など）。OPRASK の問い合わせはシミュレータのコンソールに出ます。SYSA の TSO が動いていないとジョブは投入できません。連携中は、SDSF の / コマンドとオペレーター演習は使えません（オペレーターの操作はシミュレータで行います）。画面右上の「連携を切る」で通常に戻ります。

演習：要件から JCL を書く

要件（仕様）を読んで JCL を書き、自動で採点します。「始める」を押すと、メンバー EXnn が開きます。書いたら下の「採点する」か、コマンド行に GRADE（この端末独自のコマンド）。採点は、あなたのデータセットに触れない別の環境で毎回まっさらな状態から流します。

    演習：MVS・JES2 コマンド（オペレーター）

    実際にジョブ（シナリオ）が投入されます。SDSF のコマンド行に / から始まるコマンドで状況を調べ、保留の解放、問い合わせ（WTOR）への応答 R nn,YES、ジョブの取り消しなどを行います。終わったら GRADE か「採点する」。出したコマンドの順番と、ジョブの終わり方で採点します。

      問い合わせを出すジョブは、この端末独自の練習用プログラム PGM=OPRASK（IBM の製品ではありません）を使います。PARM の文で YES/NO を尋ね、YES なら RC 0、NO なら RC 4、取り消されると S222 で終わります。

      プロシージャと INCLUDE

      JCLLIB ORDER= で指定したライブラリを順に探し、見つからなければ SYS1.PROCLIB を探します。USER01.PROCLIB には COPY と DELDS のプロシージャと、INCLUDE グループ STDPRT が入っています。=3.4 の一覧で E を付けると編集でき、コマンド行に SYS1 と入力すると SYS1.PROCLIB を表示します。

      記号EXEC の値 → PROC 文の既定値 → SET の値の順に優先されます。DD * に SYMBOLS=JCLONLY を付けるとデータ中の記号も置き換えます EXECPARM.GEN= のように手順ステップ名を付けるとそのステップだけに、付けなければ COND などは全ステップに適用されます。PARM は最初のステップに適用されます DD//GEN.SYSUT1 DD ... で上書きし、該当がなければ追加します。ステップ名のない DD は最後のステップに付きます。DSN= のように値を空にすると、その指定を取り消せます JESJCL展開後の JCL を表示します。XX はカタログ式、++ はインストリーム、X/ +/ は上書きされた行です

      構文チェック

      編集画面で JCK と入力すると、投入せずに JCL をチェックします。問題のある行を一覧で表示し、エディタの行番号が ==ERR>（エラー）や ==WRN>（警告）に変わります。RESET で印を消せます。

      JOB 文に TYPRUN=SCAN を付けて SUB すると、実行せずに JES2 の変換チェックだけを行います。

      対応範囲

      プログラム: IEFBR14、IEBGENER、SORT（ICEMAN）、IDCAMS（LISTCAT・DELETE・PRINT・REPRO）。それ以外の PGM は S806 で ABEND します。

      JCL: JOB / EXEC / DD / SET / IF・ELSE・ENDIF / PROC・PEND / JCLLIB / INCLUDE、COND、DISP、DD *、DUMMY、SYSOUT、&SYSUID などのシンボル、後方参照（DSN=*.STEP.DD）。

      実機ではなく、ブラウザ上で動くシミュレーションです。メッセージは実際の z/OS を参考にした近似で、番号や文面が実機と異なるものがあります。JCK で始まるメッセージと、末尾に (SIMULATOR MESSAGE) と付いた IEFC633I（キーワードの重複）はこの端末独自のものです。作ったデータセットとジョブはこのブラウザにだけ保存されます。
